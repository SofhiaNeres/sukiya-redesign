# Sukiya — redesign

Proposta independente de redesign do site Sukiya Brasil, com página inicial responsiva e cardápio de painéis empilhados.

## Publicação no GitHub Pages

Site estático, sem instalação ou compilação. Em Settings → Pages, selecione Deploy from a branch, branch main e pasta / (root).

- Página inicial: index.html
- Cardápio: cardapio.html
- Imagens e quadros oficiais: arquivos JPG, PNG e SVG na raiz.

Os links de delivery levam ao guia oficial de unidades. Não há integração de checkout ou processamento de pedidos neste projeto.

Fotografias, marca e quadros do cardápio pertencem ao Sukiya Brasil e foram utilizados nesta demonstração a pedido da usuária. O mapa de unidades é ilustrativo. Preços e disponibilidade devem ser confirmados na unidade escolhida.
